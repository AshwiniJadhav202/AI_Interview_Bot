# 🚀 AI Interview SaaS System

An advanced AI Mock Interview System built using:

✅ React.js Frontend  
✅ FastAPI Backend  
✅ SQLite Database  
✅ AI Voice Questions  
✅ Speech-to-Text Answers  
✅ Resume Skill Detection  
✅ Performance Scoring System  
✅ Interview History Storage  
✅ Camera + Microphone Support  

---

# 📌 Features

## ✅ User Authentication

- Login system
- User data stored in database
- Interview history saved

---

## ✅ Resume-Based AI Questions

Upload resume and system automatically:

- detects skills
- asks skill-based interview questions

Supported Skills:

- Python
- Java
- React
- SQL
- JavaScript
- HTML
- CSS
- C++

---

## ✅ AI Voice Interviewer

AI interviewer:

- speaks questions using voice
- asks questions one-by-one
- auto moves to next question after 1 minute

---

## ✅ Speech Recognition

User answers through microphone.

Features:

- live speech-to-text
- real-time answer typing
- continuous voice recognition

---

## ✅ Camera + Microphone

- live webcam preview
- microphone enabled
- camera auto OFF after interview submission

---

## ✅ Performance Evaluation

Score generated based on:

- answer quality
- answer length
- technical keywords
- communication detail

Performance Levels:

- Excellent
- Good
- Average
- Poor

---

## ✅ Future Preparation Suggestions

After interview:

- performance score
- future preparation suggestions
- interview analysis

displayed automatically.
